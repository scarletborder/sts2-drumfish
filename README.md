# sts2 Drumfish mod

增加可玩角色 Drumfish, 一个以荆棘和消耗牌为运转机制的角色

> 计划新增角色实际为东方Project的藤原妹红(碳烤鸡形态)，但目前测试版卡面和游戏中文字仍然在制作中，因此先使用代号

## Install

前往 Release 下载，并将mod文件夹保存到游戏安装目录下的mods文件，例如`mods/Drumfish/Drumfish.dll`

## Build

本mod使用模板，参考 [文档](https://github.com/Alchyr/ModTemplate-StS2/wiki/Setup) ，此文档说明了如何从源码构建并发布
